## 📦 Installation

### 📋 **Prerequisites**

- Node.js (v18 or higher)
- npm or yarn
- Gemini API key (free)

### ⚡ **Quick Setup**

```bash
# 1️⃣ Clone the repository
git clone https://github.com/FEEZAKULSOOM/ai-virtual-assistant.git

# 2️⃣ Navigate to project directory
cd ai-virtual-assistant

# 3️⃣ Install dependencies
npm install

# 4️⃣ Add your Gemini API key to gemini.js
# Edit src/gemini.js and replace the api_key value

# 5️⃣ Start development server
npm run dev

# 6️⃣ Build for production
npm run build
```

### 🔧 **API Configuration**

Edit `src/gemini.js`:

```javascript
// Replace with your own Gemini API key
let api_key = "YOUR_GEMINI_API_KEY_HERE";

import { GoogleGenAI } from '@google/genai';

async function main(prompt) {
    const ai = new GoogleGenAI({
        apiKey: api_key,
    });

    const tools = [
        {
            googleSearch: {}
        },
    ];

    const config = {
        thinkingConfig: {
            thinkingBudget: 0,
        },
        tools,
    };

    const model = 'gemini-flash-lite-latest';

    const contents = [
        {
            role: 'user',
            parts: [
                {
                    text: prompt,
                },
            ],
        },
    ];

    const response = await ai.models.generateContent({
        model,
        config,
        contents,
    });

    return response.text;
}

export default main;
```

## 🌐 API Integration

### Google Gemini AI Configuration

The application uses Google's Gemini Flash Lite model for AI responses.

| Parameter | Value |
|-----------|-------|
| **Model** | `gemini-flash-lite-latest` |
| **Tools** | Google Search enabled |
| **Thinking Budget** | 0 |
| **Response Format** | Full response (non-streaming) |
| **Text Cleaning** | Removes markdown, replaces "google" with "Fiza Farid" |

### API Call Example

```javascript
async function aiResponse(prompt) {
    let text = await main(prompt);
    let newText = text
        .replace(/\*\*/g, "")
        .replace(/\*/g, "")
        .replace(/google/gi, "Fiza Farid");
    
    const maxChars = 200;
    const displayText = newText.length > maxChars ? newText.slice(0, maxChars) + "..." : newText;

    setPrompt(displayText);
    speak(newText);
    setResponse(true);
}
```
